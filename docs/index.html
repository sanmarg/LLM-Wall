Powerful Features

Built for enterprise LLM governance

Multi-Agent Detection

5 specialized agents analyze every prompt: intent, injection, CoT, fidelity, and IOC matching for defense-in-depth security.

Zero-Trust Validation

Block prompt injection, jailbreaking, and data exfiltration before data ever leaves your network. Confidence-weighted risk scoring.

Blockchain Audit Trail

Immutable ledger for every interaction. Non-repudiation, tamper-proof logging, and forensic analysis for compliance requirements.

Distributed Threat Intel

Peer-to-peer Sentinel mesh shares threat intelligence across nodes. Automatic IOC propagation and reputation scoring.

MARL Decision Engine

Multi-Agent Reinforcement Learning adapts security policies in real-time. 4 agents (gateway, tool, context, escalate) learn optimal responses.

Coral Investigation

Cross-source SQL queries across GitHub, Sentry, Slack, PagerDuty, and Datadog. Auto-investigate threats and store results on-chain.

Coral-Powered Subsystems

🔍

IncidentInvestigator

Subscribes to A2A threat bus. On detection, runs 5 parallel Coral SQL queries (GitHub PRs, Sentry errors, Slack incidents, PagerDuty, Datadog anomalies). Results stored on blockchain ledger.

🧬

PatternHunter

Queries GitHub repos, Notion docs, and Slack channels via Coral for exposed prompts and internal terminology. Uses LLM to synthesize targeted regex patterns for the Guardian engine.

🍯

Honeypot Generator

Reads real org data (private repo names, issues) through Coral, generates deceptive decoy prompts. Unique strings registered as Sentinel IOCs for instant attacker detection.

⚙️

Policy Generator

Queries Notion (security policies), Confluence (runbooks), and GitHub (incident reports) via Coral. LLM suggests Guardian thresholds and fidelity rules tailored to your organization.

🧩

MCP Tools

3 Model Context Protocol tools: coral_sql (ad-hoc SQL), coral_list_catalog (list tables/schemas), coral_search_catalog (full-text search).

Key Components

  • Guardian Engine: 5-agent security system analyzing every prompt (Intent, Injection, CoT, Fidelity, IOC Matcher)
  • Sentinel Mesh: P2P threat intelligence network with automatic IOC propagation and reputation scoring
  • Blockchain Ledger: Immutable audit trail with proof-of-work mining, chain verification, and flush-to-disk persistence
  • MARL Engine: 4 Q-learning agents (gateway, tool, context, escalate) adapting security decisions
  • Coral Integration: Cross-source SQL investigations, pattern evolution, honeypot deployment, policy generation
  • MCP Broker: 6 Model Context Protocol tools (echo, get_time, health_check, coral_sql, coral_list_catalog, coral_search_catalog)

Request Flow

  1. Client sends prompt to LLM Wall proxy endpoint
  2. Guardian agents analyze prompt in parallel (intent, injection, CoT, fidelity, IOC)
  3. Risk score computed from weighted agent confidences
  4. Decision: allow / rate_limit / block based on configurable thresholds
  5. If threat detected, Coral IncidentInvestigator runs cross-source queries
  6. All actions logged to blockchain ledger for audit trail

Quick Start

Get up and running in 5 minutes

1

Install Coral CLI

Install Coral — the SQL query layer for APIs and databases:

curl -fsSL https://coral-ai.com/install | sh
# or: https://github.com/coral-ai/coral/releases
2

Clone & Setup

Clone the repo and create a virtual environment:

git clone https://github.com/sanmarg/LLM-Wall
cd LLM-Wall

python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate

pip install -r requirements.txt
3

Start the Server

Launch the LLM Wall proxy server:

uvicorn llm_wall.core.app:app --reload --port 9876
4

Test & Verify

Run the end-to-end test suite (63 tests covering all 12 Coral endpoints):

python test_e2e.py
5

Open Dashboard

Start the React dashboard for real-time monitoring:

cd dashboard
npm install
npm run dev
# Open http://localhost:9876/dashboard
